**Konsole Theme**
1. Download the One Dark Pro.colorscheme file
2. Copy the file to your ~/.local/share/konsole/ directory
3. Go to Settings > Configure Konsole... > Profiles
4. Click New, then name your new profile
5. In the Appearance tab, select One Dark Pro
6. Click Apply
7. Restart Konsole

**KDE Plasma Theme**
1. Download the One Dark Pro.colors file
2. In Konsole (Terminal), create the color-schemes directory
   mkdir -p ~/.local/share/color-schemes/
3. Copy the file to the color-schemes folder
4. In the System Settings app, navigate to the Appearance & Style section in the left pane, then select Colors & Themes
5. Select the Colors option from the left pane
6. Select One Dark Pro from the right pane
7. Click Apply
